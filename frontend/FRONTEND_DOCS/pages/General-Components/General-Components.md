# General Purpose Components

This section documents **shared, reusable UI components** that are used throughout the PixelPal frontend.  
These components are not tied to any specific page or feature—they provide common functionality (such as modals, overlays, buttons, or utility UI elements) that can be leveraged anywhere in the application.

- Each component listed here has its own dedicated documentation file with usage, props, and examples.
- Use these components to ensure consistency, accessibility, and maintainability across the app.

**These components are used across the entire application and are not specific to any page.**
