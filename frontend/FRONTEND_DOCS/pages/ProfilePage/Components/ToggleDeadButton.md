# ToggleDeadButton.jsx

[⬅ Back to Components Index](./Components.md)

### **ToggleDeadButton**

- **Purpose:** Button to toggle between alive and dead pet grids.
- **Inputs:**
  - `showDead` (boolean): Current toggle state
  - `setShowDead` (function): Updates toggle state
- **Outputs:**
  - Calls `setShowDead` on click to switch views
- **Usage:** Child of `ProfileHeader`.
- **Accessibility:** Has `aria-label`, keyboard focus, and tooltip.
