# Styling Conventions

[⬅ Back to Main Docs](./FRONTEND_DOCS.md)

- **CSS**: Uses modular CSS files per page/component.
- **Units**: Follows project conventions (rem, %, em for layout; px for borders/shadows).
- **Layout**: Uses Flexbox and Grid for responsive layouts.
- **Hover Effects**: Only change color, not border thickness, to avoid layout jumps.
- **Accessibility**: All interactive elements have proper roles, aria-labels, and keyboard navigation.
