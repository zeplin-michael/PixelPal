## Overview

PixelPal is a virtual pet web application where users can create, care for, and interact with digital pets. The frontend is built with **React 19**, uses **React Context** for state management, and is styled with **CSS** (with conventions for maintainability and responsiveness). The app is designed for extensibility, accessibility, and a pixel-art-inspired UI.

## Quick Reference

- **To add a new pet:** Go to Profile Page → Click "+" → Fill out modal form.
- **To select a pet:** Click on a pet card in the grid.
- **To play with a pet:** Select a pet, then go to the game page.
- **To view dead pets:** Click the tombstone toggle in the profile header.
- **To view stats info:** Click the info button on a live pet card.
